## 2. Corrections to Prior Audit Claims (Not in Version 5)
1. **Guided / Unguided / None Experimental Modes:** Version 5 evaluates only the **Guided AI** tutor. Multi-condition comparison UI is not required; `condition` defaults to `'guided'`.
2. **3–4 Frozen Tutor Holdout Cases:** Not a Version 5 requirement; excluded from formal readiness denominator.
3. **20–25% Independent Evaluator Sample & Inter-Rater Kappa:** Version 5 specifies a single primary evaluator as a known scope boundary; inter-rater agreement is not a mandatory readiness gate.
4. **12 Critical-Failure Categories:** Version 5 specifies exactly **10** critical-failure categories.
5. **Initial Case Pass Requiring Every Dimension $\ge 3$:** Version 5 defines initial case pass as `noCriticalFailure && applicableMean >= 3.5`. The `every applicable rating >= 3` floor applies to the **latest verified execution for final readiness**.
