## 2. Claims from Prior Audit Rejected / Not in Version 5
- **Three experimental modes (`guided`, `unguided`, `none`)**: **NOT IN VERSION 5** — Version 5 evaluates only the Guided AI tutor.
- **3–4 frozen tutor holdout cases**: **NOT IN VERSION 5** — Excluded from formal denominator and readiness gates.
- **20–25% independent evaluator subset & inter-rater agreement**: **NOT IN VERSION 5** — Single primary evaluator is explicitly documented in Version 5.
- **12 critical-failure categories**: **NOT IN VERSION 5** — Replaced with the exact 10 Version 5 critical-failure categories.
- **Initial case pass requires every applicable dimension $\ge 3$**: **NOT IN VERSION 5** — Separated into `initialCasePass` (`!hasCriticalFailure && applicableMean >= 3.5`) and `latestExecutionMeetsRatingFloor` (`all applicable ratings >= 3`).
